# 拆標報告模板

存成 `01_拆標/拆標報告.md`。每一格都要附出處(檔名 + 頁碼或條號);找不到就寫「招標文件未載明」,不要猜。

## 0. 文件盤點

| 文件 | 檔名 | 已讀 | 備註(掃描檔、缺頁、版本) |
|---|---|---|---|
| 公告 | | | |
| 投標須知 | | | |
| 評審(選)須知 | | | |
| 需求說明書 / 規範 | | | |
| 契約(草案) | | | |
| 標價清單 / 價目表 | | | |
| 表單附件 | | | |
| 補充 / 更正 / Q&A | | | 以最新版為準 |

## 1. 基本資料

案名、案號、機關與承辦單位、預算金額、採購金額級距、履約期間、履約地點、採購方式(公開招標最低標 / 最有利標 / 經公開評選之限制性招標 / 其他)、依據法條、電子領標與電子投標與否、截止投標時間、開標或評審時間與地點。

## 2. 資格條件

| 編號 | 條件原文 | 證明文件 | 本公司是否符合 | 證據或缺口 | 出處 |
|---|---|---|---|---|---|

重點:公司登記、營業項目、納稅證明、信用證明、財力證明、實績(件數、金額、年限)、人員資格、廠商不得有的情形(拒絕往來、停權等)。

## 3. 不合格與廢標條款

逐條列出,每條一列:

| 條款原文 | 觸發情形 | 本案風險 | 防範做法 | 出處 |
|---|---|---|---|---|

常見:未依招標文件規定投標、文件內容不符、未檢附領標憑據、逾時、封套標示錯誤、簽章不全、資格文件逾期、以不實文件投標(參考 `tw-procurement-basics.md` 第 50 條)。

## 4. 評審方式

- 評定方式:序位法 / 總評分法(看勾選)。合格分數:__。同分處理:__。
- 評審項目表:

| 項次 | 評審項目 | 子項 | 配分 | 評審重點(原文) |
|---|---|---|---|---|

- 價格如何計入:__(納入評分 / 單獨議價 / 其他)。
- 簡報:是否要簡報、時間、人數、可用設備、可否更動投標內容。
- 盲評:企劃書與簡報能否載明廠商名稱、Logo、人名。**會影響整份文件的寫法,務必確認。**
- 議價與決標方式,未得標廠商有無獎勵金。

## 5. 履約條件

履約期程與里程碑、交付項目與規格、驗收方式、付款條件、保固、押標金與履約保證金(金額、方式、退還)、罰則與違約金、智慧財產權(著作權歸屬、授權)、保密、資通安全、廉政、分包與轉包限制、保險。

## 6. 應繳文件清單

對照 `forms-checklist.md`。列出:文件名、份數、是否有機關範本、是否需簽章 / 用印、放哪個封套。

## 7. 疑點與釋疑問題

| 問題 | 為什麼重要 | 釋疑截止日 | 出處 |
|---|---|---|---|

釋疑通常有截止時間(須知會載明),過了就不能問。

## 8. 初步判斷(寫給使用者看)

- 我們符合資格嗎?缺什麼?
- 競爭與勝算:評審項目哪些我們強、哪些弱?
- 成本與利潤的粗估範圍(參考 profile 的 `pricing_reference` 指向的報價資料)。
- 建議:投 / 不投 / 需先補件,並說明理由。

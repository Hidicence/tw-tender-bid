## 為什麼不直接安裝這些 skill

1. 幾乎都以中國大陸法規為前提(招標投標法、政府採購法大陸版、技術標與商務標、廢標),台灣是政府採購法,流程與術語不同。
2. 台灣標案常見的是「經公開評選之限制性招標」與最有利標,重點在評審項目、簡報與價格合理性,不是工程類的技術標與商務標分冊。
3. 各公司有自己的版面、簽章與報價規則,需要接到既有腳本與報價資料,所以本 skill 把公司資料抽成 profile,版面做成可切換主題。
4. 多數沒有授權檔,不能直接複製。

## 可以再考慮的做法

- `bahayonghang/.../bidwriter/references/` 的 `SCORING_GUIDE.md` 與 `CHAPTER_TEMPLATES.md` 是 MIT,如需要更多寫作範本,可在保留授權聲明的前提下引用;目前未採用,因為內容偏工程領域。
- 如果之後有台灣的 GitHub 專案(例如 g0v 的政府採購公報、標案查詢工具,搜尋時看到 `Yippine/Corp-Insight`、`mikematw0316-labbot/tender-scraper-web` 這類),可用來做「商機與歷史得標資料」查詢,屬另一種用途。

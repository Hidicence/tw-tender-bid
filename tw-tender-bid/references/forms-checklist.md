# 應繳文件、表單與封套清單

來源:多份實際標案的招標附件(已去識別化)。每案實際要繳什麼以該案須知為準,先看須知的「投標文件」「資格文件」「封裝」章節。

## 一、實際標案中出現過的文件

「常見度」是在多份樣本中出現的大致頻率,不是精確統計。

| 文件 | 備註 | 常見度 |
|---|---|---|
| 投標廠商聲明書 | 機關附範本,依範本填寫、簽章 | 多數案件 |
| 投標標價單 / 標價清單 / 詳細價目表 | 項目與企劃書一致;金額以使用者確認為準 | 多數案件 |
| 切結書(投標時檢附) | 機關附範本 | 少數案件 |
| 投標書(含總價大寫) | | 少數案件 |
| 投標廠商印模單 | 公司章、負責人章 | 少數案件 |
| 投標資格審查表 | 資格自我檢核 | 少數案件 |
| 外標封 / 證件封 / 標單封 / 服務建議書封 | 封套標示格式依須知,封面標籤要核對案名案號 | 部分案件 |
| 授權書 | 授權代理人或授權使用 | 少數案件 |
| 著作人約定書 | 著作權相關 | 少數案件 |
| 廉政相關規定告知書 | 機關契約附件,須知有要求時才簽 | 少數案件 |
| 廠商資通安全管理約定書 | 機關契約附件 | 少數案件 |
| 廠商參與政府採購可能涉及之法律責任 | 告知文件 | 部分案件 |
| 公職人員及關係人身分關係揭露表 | | 少數案件 |
| 電子領標憑據 | 未檢附可能為不合格標 | 部分案件 |
| 投標廠商合作同意書 / 合作意向書 | 協力或分包單位的同意文件(範本可放在 profile 的 `reusable_assets`) | 視是否有協力單位 |
| 服務建議書 / 企劃書 | 對著評審項目寫 | 全部 |
| 團隊經歷、設備、作品 | 附在建議書 | 多數 |

## 二、須知通常會列、但樣本中沒有範本的項目(逐案確認)

營業登記證明、納稅證明、信用證明、財力證明(視須知)、公司章程或登記資料、押標金繳納證明(若收取)、授權代理人身分證明、類似案件實績證明(契約、驗收證明)。**是否要、要什麼格式,一律看該案須知。**

## 三、封套與份數檢查

- 外標封標示:案名、案號、廠商名稱與地址、投標或開標日期、收件單位。
- 內封套 / 分封套(資格、規格、價格)的數量與名稱。
- 正本與副本份數、是否需用印、是否需騎縫章。
- 裝訂方式(膠裝、夾子)、頁碼、是否需雙面。
- 遞送方式:電子投標、郵寄、親送;截止時間以政府電子採購網公告為準。
- 盲評案:服務建議書不得出現公司名、Logo、人名、可辨識的作品署名。

## 四、簽章規則

- 簽名與印章使用公司既有去背檔(路徑記在 profile 的 `seals_and_signature`,不放進 skill 資料夾)。
- **不得在使用者未逐份確認前蓋章或簽名。** 先產出未蓋章版本,使用者確認哪些文件要蓋、蓋在哪裡,再用 `--seals` 產出蓋章版本。
- 蓋章位置遵照機關範本標示(例:「廠商印章」「負責人簽章」欄)。
